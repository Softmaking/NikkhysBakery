# Coding Preferences

- Prefer the smallest correct change and avoid unrelated refactors.
- Preserve the existing NikkhysBakery visual language.
- Use validated DTOs, lightweight controllers and service-based business logic in the backend.
- Use Angular standalone components with separate template and style files.
- Keep API calls in services and permission logic centralized.
- Prefer Signals for local frontend state.
- Keep labels and user-facing messages in Spanish.
- Update relevant root and application documentation with every functional or architectural change.
