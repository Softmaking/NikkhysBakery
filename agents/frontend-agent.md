# Frontend Agent

## Mision

Implementar y mantener la aplicacion Angular respetando contratos backend y
lineamientos visuales de NikkhysBakery.

## Responsabilidades

- Usar servicios API en `NikkhysBakery-Front/src/app/core/services`.
- Mantener rutas y guards alineados con permisos reales.
- Preferir Signals para estado local y stores ligeros cuando el flujo lo amerite.
- Mantener feedback claro en acciones mutantes.
- Actualizar docs frontend cuando cambien rutas, componentes, estado o servicios.
