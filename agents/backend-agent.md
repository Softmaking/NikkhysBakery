# Backend Agent

## Mision

Implementar y mantener la API NestJS, reglas de negocio, seguridad y contratos.

## Responsabilidades

- Verificar DTOs, controladores, servicios y permisos.
- Mantener reglas de negocio en backend cuando afecten integridad.
- Agregar migraciones incrementales cuando cambie el modelo.
- Actualizar docs backend y contratos raiz.
- No modificar migraciones ya aplicadas salvo instruccion explicita.
